
## [Discovering Statistics Using JASP: A Teaching Guide](https://jasp-stats.org/2025/04/12/discovering-statistics-using-jasp-a-teaching-guide/)

## What is JASP?

**JASP (Jeffrey’s Amazing Statistics Program)** is a free, open-source statistical software designed for **ease of use, transparency, and reproducibility**. It features an intuitive point-and-click interface, dynamic output that updates in real-time, and integrated support for both **frequentist** and **Bayesian** analyses. Built on R and backed by academic institutions, JASP bridges the gap between spreadsheet simplicity and R-level analytical power—making it ideal for education and accessible research.


## 1. Ease of Use

* Clean, intuitive UI with progressive disclosure: students see only what they need.
* Tick-box options dynamically update statistics and visual output—ideal for teaching.

## 2. Accessibility & Installation

* Free, cross-platform (Windows, Mac, Linux), open-source, and multilingual.

## 3. Modular Statistical Analysis

* Core analyses include descriptives, t-tests, ANOVA, regression.
* Optional modules like mediation, SEM, and machine learning can be toggled on.

## 4. Data Visualization

* Offers high-quality visualizations, including **raincloud plots**—great for illustrating group differences with clarity.

## 5. Reproducibility

* Saves entire analysis (.jasp file) including data, settings, and output.
* Outputs are exportable (PDF, HTML, LaTeX), and equivalent R code is displayed for transparency.

## 6. Community & Support

* Over 355 universities worldwide use JASP in classrooms.
* Active forums, GitHub, documentation, and institutional support through the JASP Community.

## 7. Teaching Support & Resources

* Companion website provides datasets, exercises, annotated files, and webinar content to support classroom adoption.
